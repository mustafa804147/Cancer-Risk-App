# Cancer Risk App (Android - Java)

This Android application is developed using Java in Android Studio. It is designed to help users assess potential cancer risk factors through a simple questionnaire-based system.

## Features:
- User-friendly interface
- Questionnaire-based risk evaluation
- Instant result generation
- Health awareness tips
- Lightweight Android application

## Technology Used:
- Java
- XML
- Android Studio

## Purpose:
This application is developed for educational and awareness purposes only. It does not provide medical diagnosis or treatment.

## Disclaimer:
Always consult a qualified doctor for medical advice.
